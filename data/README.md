# V1 Sensory Coding in an Autism Mouse Model

Two-photon calcium imaging analysis of population coding in V1, comparing 
the BTBR mouse model of autism to C57BL/6J controls. PhD dissertation 
project, Instituto de Fisiología Celular, UNAM.


Raw imaging data (two-photon calcium imaging) is not included in this 
repository due to its size and because it contains unpublished information.

Depositing it on DANDI Archive is being considered for the future, 
subject to authorization.
